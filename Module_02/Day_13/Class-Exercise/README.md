# Habesha Eatery Menu Card

## Description

This project styles a Habesha Eatery menu card using CSS.

## Features

- Global reset with `box-sizing: border-box`
- CSS custom properties (variables)
- Typography styling
- Box model (padding, border)
- Gold top border accent
- Hover effect using `:hover`
- Price prefix using `::before`
- Zebra-striped ingredient list using `:nth-child(even)`

## Technologies Used

- HTML5
- CSS3
