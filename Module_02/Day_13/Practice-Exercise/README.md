# Day 13 - Habesha Eatery Menu Card

## Objective

Style a Habesha Eatery menu card using CSS.

## Features

- CSS variables (`:root`)
- Box model
- Typography
- Hover effect (`:hover`)
- Price prefix using `::before`
- Zebra-striped ingredients using `:nth-child(even)`
