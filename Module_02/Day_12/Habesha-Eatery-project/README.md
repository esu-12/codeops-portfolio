# Habesha Eatery

## Description

A two-page restaurant website built using semantic HTML5.

## Features

- Reservation form
- Contact form
- Menu table
- Opening hours table
- Restaurant image
- Google Maps location
- Accessible HTML
- Semantic landmarks

## Technologies

- HTML5
- CSS3

## Validation

Validated using the W3C HTML Validator with no errors.
